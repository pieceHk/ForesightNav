# 标定期间的独立分析工具核查

运行源文件、配置和固定清单保持冻结。以下工具放在 `results/exp4/code/`，不参与导航或候选排序；它们为 CP2–CP5 的汇总和审阅做准备。

## 已验证的功能

| 项目 | 证据 |
| --- | --- |
| 原指标复用 | 在三个完整原版 episode 上，汇总的 SR/SPL/PR 与 `experiments.metrics` 一致 |
| 条件成功率 | 只在前序成功的子集上计算，Joint 与 SR 相等；已覆盖前阶段失败、后阶段成功的案例 |
| PPL | 明确作为新增实现，采用全部目标 PR × 成功前缀路径效率，另保留 prefix-only 版本 |
| 2×2 主效应和交互项 | 人工可手算案例通过，单位为百分点；配对比较拒绝不同 episode 集合 |
| 无效访问路径 | 管线样本重建为 1.000000 m，原评估器失败阶段路径为 1.000004 m；重叠访问区间不重复计数 |
| 轨迹图 | CPU 读取原场景 navmesh，叠加真实轨迹、候选 B 和所选候选；诊断样本已渲染检查，未使用 GPU 渲染或改变运行观测 |
| CP2 统计流程 | 在临时合成数据上，稳定合并与不稳定交叉拟合两分支均跑通，每组 200/200 次 bootstrap；GT 未进入参数提案，未创建冻结参数文件 |

`report_variants.py` 对正式结果要求：原生运行完整结束、身份与目标顺序覆盖固定清单、实际变体正确、快照中的参数与冻结参数一致、无未审阅的结构性规划或记录错误。输出按 `logs/` 和 `summary/` 分开。Nearest 的无约束、滞回后和实际下发偏离率分别汇总。递归空集状态计数与真正发生回退的决策数也分开。

当前管线图只展示影子 BLP 建议与旧版实际轨迹，已在图中标为 diagnostic only，不作为 Full BLP 成绩或 CP3 冒烟结果。正式图将选择每阶段首个已实际下发、且包含至少两个候选的快照；不存在时使用首个非空已下发快照。若访问路径归属存在歧义，汇总工具会要求逐动作审计，不会把不完整路径当作最终过程指标。

## 拟合数值处理

原拟合器在合成测试的少量 bootstrap 重采样上返回数值优化失败状态。独立分析入口 `fit_calibration_reviewed.py` 仅对这种失败重试同一个正斜率逻辑回归 MLE，使用均值负对数似然、解析梯度和约束 KKT 检查。目标函数的最优点不变；缺失标签、一类标签或完全分离仍报错。重试后两种测试情形的全部重采样均完成。运行中的源码没有修改，真实数据尚未执行这一步。

翻转率按设计中的“所有快照”给出主分母：空根候选集时，两组参数都选择 None，记作不翻转；另给出仅在非空候选集上的条件翻转率和两个分母。此口径在真实拟合前固定，检查用例已验证两个分母的差异。

## 标定与评估数据范围

身份审计未读取评估成绩。按设计先收集的 360 条 2-MON 来自 12 个场景；400 条 3-MON 覆盖 20 个场景。两者共享这 12 个场景及 720 个底层 source episode。3-MON 中有 12 条的前两个目标来源顺序与标定序列相同。

因此，不同的 2-MON/3-MON episode 文件不代表场景或底层目标独立。后续报告会明确这是所给设计下的自标定机制消融，不把它描述为独立场景、独立目标的泛化测试。原分组和清单保持不变。
