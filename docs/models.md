# Model assets

[assets/models.json](../assets/models.json) pins the 22 files used by default mapping and navigation, including auxiliary weights, SEEM tokenizer files and two Hugging Face snapshots. The prepared directory occupies 5.63 GB. Model packages are not imported during preparation.

## Prepare

On a computer with internet access:

```bash
python scripts/prepare_models.py --output /path/to/pbsp-weights
```

The EmbodiedSplat release supplies three selected weights inside a 6.98 GB archive. Extraction needs `zstd`; use `--zstd .cache/envs/mapping/bin/zstd` to select the executable installed with the mapping environment. The script extracts only the selected files. Other models download separately from their original providers.

For an offline server, prepare the cache on the connected computer:

```bash
python scripts/prepare_models.py --download-only --cache ./offline-pbsp/models
```

Copy the cache to the server, then run:

```bash
python scripts/prepare_models.py --offline --cache /path/to/offline-pbsp/models \
  --output /path/to/pbsp-weights --zstd .cache/envs/mapping/bin/zstd
```

Download and extraction validation against the public model sources is in progress. The manifest hashes identify the existing weights used by the controlled inference replays.

## Import an existing set

```bash
python scripts/prepare_models.py --source /path/to/existing-weights --output /path/to/pbsp-weights
python scripts/prepare_models.py --verify --output /path/to/pbsp-weights
```

Import checks every source and existing destination before copying. It copies selected files, creates the two pinned Hugging Face revision references and verifies the result. It does not replace files with different contents. `--verify` checks without modifying files or accessing the network.

## Sources

| Resource | Provider |
| --- | --- |
| Reconstruction, FastSAM and MaskAdapter | [EmbodiedSplat](https://github.com/0nandon/EmbodiedSplat), [released archive](https://huggingface.co/datasets/onandon/EmbodiedSplat/tree/60307f90694e57dc364ac72795b9c6a7bd1e0437) |
| EfficientNetV2 | [timm model configuration](https://github.com/huggingface/pytorch-image-models/blob/v0.4.12/timm/models/efficientnet.py) |
| MobileCLIP-S0 | [Apple's download script](https://github.com/apple/ml-mobileclip/blob/main/get_pretrained_models.sh) |
| Detic | [Detic model zoo](https://github.com/facebookresearch/Detic/blob/main/docs/MODEL_ZOO.md) |
| SEEM Focal-L v0 | [SEEM checkpoint](https://huggingface.co/xdecoder/SEEM/tree/25e2cc7d8398236bd7ea519f92ca2efed835739c) |
| CLIP and tokenizer | [OpenAI CLIP](https://github.com/openai/CLIP), [tokenizer snapshot](https://huggingface.co/openai/clip-vit-base-patch32/tree/3d74acf9a28c67741b2f4f2ea7635f0aaf6f0268) |
| OpenCLIP | [ConvNeXt snapshot](https://huggingface.co/laion/CLIP-convnext_large_d_320.laion2B-s29B-b131K-ft-soup/tree/654d0f80ff73c58e7281a3ca7dc425589049e2e1), [ViT-B/16 snapshot](https://huggingface.co/laion/CLIP-ViT-B-16-laion2B-s34B-b88K/tree/7288da5a0d6f0b51c4a2b27c624837a9236d0112) |
| Image matching | [SuperGlue](https://github.com/magicleap/SuperGluePretrainedNetwork), [DISK](https://github.com/cvlab-epfl/disk), [LightGlue](https://github.com/cvg/LightGlue) |

The filenames and hashes preserve the validated models. Model and dataset licenses remain with their providers; see [third-party notices](../THIRD_PARTY_NOTICES.md).

The native mapping factory passes `MappingModelResources` explicitly. Direct compatibility construction also accepts `ES_TIMM_EFFV2_WEIGHTS`; its default EfficientNet path is `pretrained/tf_efficientnetv2_s_21ft1k-d7dafa41.pth` relative to the mapping engine.

SuperGlue's inference source is prepared separately by `prepare_runtime.py` or `prepare_dependencies.py`. The navigation environment cache includes its six fixed source files. Their generated bytes match the retained matching implementation, including batching behavior and explicit checkpoint selection. See its [source manifest](../assets/superglue.json) and [research-use license](../third_party/licenses/superglue/LICENSE).
